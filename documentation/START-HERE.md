# ¡BIENVENIDO A TURNOFLOW AI! 🚀

Gracias por adquirir **TurnoFlow AI — Recepción Inteligente 24/7**, el producto digital y kit de implementación integral diseñado para automatizar la atención comercial, captura de prospectos y agendamiento de turnos en centros de estética, salones de belleza y profesionales independientes.

---

## ¿Qué acabas de adquirir?
Este paquete te entrega un sistema llave en mano de nivel empresarial compuesto por:
1. **Plataforma de Gestión (Panel Expo Web/Mobile)**: Dashboard de analíticas, CRM de leads, agenda de turnos, base de conocimiento y Playground de IA.
2. **Backend de Orquestación (NestJS + PostgreSQL)**: Motor multi-agente con tool calling, guardrails de seguridad y control multi-tenant.
3. **Flujos de Automatización Listos para n8n**: Workflows JSON oficiales para WhatsApp Cloud API, sincronización con Google Sheets y Calendar, y transferencia humana.
4. **Prompts y Lógica de Agentes Especializados**: Instrucciones blindadas contra alucinaciones para Recepción, Clasificación de Leads, Reservas y Seguimiento.
5. **Plantillas CSV de Puesta en Marcha Rápida**: Catálogo de servicios, preguntas frecuentes y configuración de turnos.
